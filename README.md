# 🍽️ Plano Alimentar Personalizado

Plano de refeições nutritivo personalizado para Daniel e Jessica com interface mobile-friendly.

## ✨ Funcionalidades

- 🔵 **Daniel:** 6 refeições diárias (06:00–22:00)
- 🩷 **Jessica:** 5 refeições diárias (07:00–22:00)
- 👨‍🍳 **Receitas:** 20+ receitas com ingredientes e modo de preparo
- ✅ Marcação de progresso diário
- 🔗 Atalhos rápidos para cada horário
- 🏠 Botão Home para fácil navegação
- 📱 Totalmente responsivo (funciona no celular)
- 💾 Funciona offline (sem internet)
